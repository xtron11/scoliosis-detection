# Scoliosis Detection

Простая свёрточная нейросеть (CNN) на TensorFlow/Keras, которая по рентгеновскому снимку позвоночника определяет: **норма** или **сколиоз**.

## Как это работает

1. `main.py` загружает изображения из папок датасета (`image_dataset_from_directory`) и приводит их к 180×180: обучающая выборка берётся из `data_filtered/`, валидационная — из `data/` (split 80/20).
2. Модель: аугментация (отражение, поворот, зум) → нормализация → 2 блока Conv2D + MaxPooling → Dense(128) + Dropout → сигмоида на выходе (бинарная классификация).
3. Обучение 20 эпох (Adam, binary cross-entropy), строится график точности, модель сохраняется в `scoliosis_model.h5`.
4. `predict.py` загружает сохранённую модель и выдаёт предсказание для одного снимка.

## Датасет

Датасет в репозиторий не входит. Ожидаемая структура (по папке на класс):

```
data_filtered/
  Normal/   # снимки без патологии
  Scol/     # снимки со сколиозом
```

Папка `data/` в исходной версии дополнительно содержала класс `Spond` (спондилолистез).

## Запуск

```bash
python -m venv venv
venv\Scripts\activate            # Linux/macOS: source venv/bin/activate
pip install -r requirements.txt

python main.py                   # обучение, на выходе scoliosis_model.h5
python predict.py                # предсказание для normal.jpg (путь меняется в коде)
```
